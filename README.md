# DiskBackup_and_check-sum
Prosty skrypt do tworzenia kopii obrazow nosnikow oraz sprawdzenia sum kontrolnych
# How to use?
./script.sh {sciezka do pliku ktorego chcemy zrobic kopie}
Plik kopii powinien sie zapisac w katalogu /var/backup wraz z plikiem .txt zawierajacym sumy kontrolne nowo utworzonych plikow.
